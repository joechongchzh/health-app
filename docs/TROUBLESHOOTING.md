# 故障排除

## 收不到登录链接

检查垃圾邮件、邮箱拼写和 Supabase Auth 配置；等待一分钟后再试。不要把登录链接发给他人。

## 邀请码无效

可能已过期、达到最大使用次数或被停用。请联系维护者重新生成。

## 显示离线待同步

记录仍在本机。恢复网络并重新打开应用，或点击顶部状态手动同步。不要在同步失败时清除浏览器网站数据。

## iPhone 没有安装按钮

必须用 Safari 打开，再点分享→添加到主屏幕。微信内置浏览器不支持完整安装流程。

## AI 接口失败

确认 Base URL 为 HTTPS、没有嵌入账号密码、模型名正确且 Key 有效。生产环境拒绝 localhost 和 HTTP。

## 更新后界面仍是旧版

点击应用内“立即更新”，或完全关闭主屏幕应用后重新打开；仍无效时再清除该站点缓存，但应先导出 JSON 备份并确认同步完成。
