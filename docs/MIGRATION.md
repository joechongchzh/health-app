# v2 到 v3 迁移

首次登录后应用检测 `localStorage.ht_data_v1`，先展示各类记录数量。确认后自动下载原始 JSON 备份，再将日期、饮食、训练、体重、食物、套餐、补剂和训练方案写入 IndexedDB/outbox。

迁移 ID 基于用户、类型和旧记录位置稳定生成。重复执行时不会产生重复记录。迁移完成后先核对数量；只有用户第二次明确确认才删除旧 localStorage。

旧 `health-data` JSON 可在“我的→安装与数据”中直接导入，应用会自动识别并调用旧格式适配器；v3 原生导出标记为 `health-data-v3`。

安全提醒：如果旧数据曾包含 GitHub Token 或 AI Key，应在对应平台撤销并重新生成。删除文件或提交无法清除 Git 历史。
