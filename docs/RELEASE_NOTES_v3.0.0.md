# v3.0.0

健康追踪从单文件应用升级为 React + TypeScript + Vite PWA 正式版。

主要变化：

- 邮箱验证码、邀请码注册、RLS 账号隔离与多设备同步
- IndexedDB 本地优先、条目级版本/软删除/冲突提示
- 旧版数据备份和幂等迁移、v3 JSON 导入导出
- 通用身体档案、目标和训练方案，不再内置 Joe 的个人默认值
- 五栏移动端界面、iOS/Android 主屏幕安装与更新提示
- AI 文字/视觉/语音接口分开配置，Key 只保存在本机
- 完整中文开源文档、测试、CI、CodeQL 与 GitHub Pages 部署

已知限制：iOS 不依赖后台同步；AI 兼容性取决于接口服务商；餐馆和图片识别数据为估算。
